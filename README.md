# weekendholdet.github.io

Info site for Weekend holdet (developer page for Google Play). No games are hosted here.

- `index.html` – front page with the list of games and contact
- `mormor/` – Mormor mod sneglene: info page + `privatliv.html` (privacy policy, link it in Play Console)
- `app-ads.txt` – add it when the AdMob publisher id exists. One line:
  `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`

Hosted with GitHub Pages from the repo `weekendholdet/weekendholdet.github.io` (branch `main`, root).
When the game is live: replace the "Snart på Google Play" badges with the Play Store link.
